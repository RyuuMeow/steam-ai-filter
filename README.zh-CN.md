# Steam AI Filter — Steam AI 生成内容过滤器

[繁體中文](README.md) · [English](README.en.md) · [简体中文](README.zh-CN.md)

在 Chrome 浏览 Steam 商店时，依开发者的 AI 使用披露过滤游戏。可以选择 AI 用途，并标记、遮罩或隐藏匹配的游戏卡片；默认只开启美术类别。

当前源代码版本为 **v0.10.0（尚未发布）**，可直接加载编译好的 [extension/](extension/) 文件夹。已发布的 **v0.8.0** 安装包可从 [Releases](https://github.com/RyuuMeow/steam-ai-filter/releases/latest) 或 [RAR 下载链接](https://github.com/RyuuMeow/steam-ai-filter/releases/download/v0.8.0/steam-ai-filter-v0.8.0.rar) 获取。以下功能说明对应 v0.10.0；安装编译好的扩展不需要 Node.js。

## 安装

1. 下载并解压 v0.8.0 Release 的 RAR，或通过 **Code → Download ZIP** 下载并完整解压本仓库。使用仓库时，选择其中的 `extension/` 文件夹。
2. 打开 `chrome://extensions`，开启**开发者模式**，点击**加载已解压的扩展程序**。
3. 选择直接包含 `manifest.json` 的扩展文件夹。安装后请保留该文件夹。
4. 刷新所有 Steam 商店标签页。从 Chrome 扩展菜单固定 **Steam AI Filter**，点击其图标打开设置。

[繁体中文安装指南](README.md#安裝)附有截图；截图来自较早版本，工具栏入口相同。

## 使用

| 模式 | 效果 |
|---|---|
| 关闭 | 还原卡片、移除标记并停止检查 |
| 标记 | 在匹配游戏上显示 AI 与用途标签 |
| 遮罩（默认） | 用强烈模糊的毛玻璃遮罩覆盖匹配卡片，保留位置；点击一次显示该游戏 |
| 隐藏 | 收起匹配的完整游戏区块 |

- **过滤项目**：美术、音乐／音效、配音、剧情／文本、翻译、代码、用途不明。任一所选用途匹配就会处理。用途不明表示有正式披露但无法分类；尚未检查或查询失败不算。取消全部类别后，不再标记、遮罩、隐藏，也不新增自动忽略。
- **检查图标**：绿勾表示已检查、未匹配所选用途；黄勾表示匹配所选用途。遮罩和隐藏的卡片不显示勾。未匹配**不代表没有使用 AI**。
- **界面语言**：支持 English、繁體中文、简体中文。首次跟随浏览器语言，可在**设置 → 语言**切换；开发者的 Steam 披露原文保持不变。
- **遮罩操作**：遮罩显示「AI生成内容」；鼠标悬停或键盘聚焦时，淡入「解除遮罩」「允许此游戏」「不感兴趣」三个按钮。
- **解除遮罩**：点击按钮或遮罩空白处，只显示该游戏在当前页面的卡片，不打开对话框，也不跳转；角落会出现眼睛图标按钮，点击可恢复遮罩。切换模式后重置。
- **鼠标悬停显示**：在「设置 → 显示设置」开启，默认关闭；仅在鼠标停留卡片时临时解除遮罩，移出立即恢复。手动点击则持续显示，直到点击眼睛或切换模式。
- **允许此游戏**：加入永久显示的例外列表，可在设置中移除。也可从标记或已隐藏游戏列表查看披露并设置例外。
- **不感兴趣**：明确点击后，将这款游戏加入当前 Steam 账号的忽略列表；这是单次账号操作，不会开启「自动不感兴趣」。
- **缓存与网络**：默认有披露缓存 7 天，未找到披露缓存 1 天；可改为固定 1／7／30 天。默认请求间隔为 0.7 秒，最多并发 2 个，由所有标签页共用。
- **自动不感兴趣**：默认关闭。在遮罩或隐藏模式下，将匹配游戏加入当前 Steam 账号的忽略列表，每 30 秒最多处理一款。关闭不会撤销已完成的操作。设置中显示实际队列、确认结果、暂停或限流状态。

## 更新

将新版文件覆盖到 Chrome 已加载的文件夹，在 `chrome://extensions` 重新加载扩展，再刷新所有 Steam 商店标签页。使用源代码编译版本时，应显示 **0.10.0**。扩展更新后出现 `Extension context invalidated`，刷新 Steam 页面即可。

## 支持范围与隐私

- 适用于桌面版 Chrome 的 `store.steampowered.com`，包括首页、搜索和特卖页面；不适用于原生 Steam 客户端或 Steam 社区。
- 依据正式 AI 披露与本地关键词判断，不分析画风。未知、查询失败或需要登录／年龄验证的游戏保持可见；首次查询时卡片可能短暂出现。
- 设置、例外和缓存保存在本地；没有 AI API、共享数据库或第三方追踪。网络请求仅发往 Steam 商店，并使用浏览器现有的 Steam 登录状态。
- `storage` 用于保存本地数据，`alarms` 用于调度自动忽略；网站访问仅限 Steam 商店。

更多[使用与数据处理说明](docs/usage.md)以繁体中文维护。Steam 页面结构更改可能需要更新扩展。

## 开发

使用 Node.js 22 或更新版本：

```sh
npm ci
npm run check
npm run package
npm run dev
```

`src/` 为 TypeScript 源代码，`public/` 为静态资源，`extension/` 为可安装的编译产物。参见[开发指南](docs/development.md)与[验证记录](docs/validation.md)。推送版本标签后会自动检查并创建包含扩展 RAR 的 GitHub Release。
