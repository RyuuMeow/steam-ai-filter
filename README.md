# Steam AI Filter · v0.3.0

Chrome 桌面版 Steam 商店過濾插件。讀取頁面訊號，按需查詢遊戲詳情並快取在本機，依拉桿設定標示或遮蔽遊戲。

## 安裝

1. 開啟 Chrome 的 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 點「載入未封裝項目」，選擇交付的 **steam-ai-filter** 資料夾（裡面直接有 manifest.json）。
4. 重新整理已開啟的 Steam 首頁、搜尋頁或遊戲頁，再從工具列開啟插件。

已提供編譯後的插件，安裝不需要 Node.js。ZIP 請先解壓縮，勿直接選 ZIP。

## 更新舊版

以新版檔案覆蓋原本載入的插件資料夾（不要多包一層子目錄），在 `chrome://extensions` 點插件的重新載入按鈕，確認版本是 **0.3.0**，再重新整理 Steam 首頁。只重新整理 Steam 不會讓 Chrome 重新讀取新的 manifest。新版為背景查詢新增 `store.steampowered.com` 的主機權限；若 Chrome 顯示網站存取提示，需允許 Steam 商店。

## 使用

| 檔位 | 規則 | 拉桿 |
|---|---|---|
| 關閉 | 移除插件的頁面標示與遮蔽 | 灰色 |
| 標示（預設） | 標出 AI 揭露或人工智慧 tag，全部保留 | 淡藍、柔光 |
| 揭露 | 背景確認商品頁，遮蔽有 AI 揭露的遊戲 | 飽和藍、較強光暈 |
| 廣泛 | 額外遮蔽人工智慧 tag 命中的遊戲 | 藍紫、切入時短暫流光 |

拖曳中預覽拉桿效果，放開後套用。支援鍵盤方向鍵、Home、End，以及系統的減少動畫設定。

- 被封鎖的卡片保留原尺寸，以純底色、垃圾桶圖示及原因文字遮蔽。已揭露者顯示「AI 生成內容」，只有 tag 者顯示「人工智慧標籤」。點擊遮罩可查看原因與例外。
- 頁面上可「暫時顯示」及「恢復過濾」。這個暫時狀態在刷新頁面或變更等級時結束。
- 點卡片標籤，或展開「查看命中原因與例外」，可查看依據並設為「永遠顯示」。
- 彈窗底部可移除「永遠顯示」的遊戲。
- 等級、例外名單與查詢結果保存在本機；不使用 AI API，不上傳到共用資料庫。

## 動態查詢與快取

- 標示、揭露及廣泛檔會優先查畫面內與上下 400px 內的未知遊戲。廣泛檔已因 tag 遮蔽的遊戲不再補查；永遠顯示的遊戲也不補查。
- 只下載 Steam 商品頁 HTML，不開新分頁、不執行下載的腳本、不載入其圖片或影片。請求不攜帶 Steam 登入 cookie；Steam 仍會收到查詢的 App ID 與一般連線資訊。
- 不同分頁共用背景佇列：同款進行中的查詢合併，最多同時兩個請求，開始時間至少間隔 700ms。背景分頁不再排入新查詢；關閉過濾會取消佇列及進行中的請求。
- 有披露快取 7 天，完整商品頁未找到披露快取 1 天，失敗快取 5 分鐘；最多保存最近 500 筆。過期後遇到該遊戲才重新查詢。
- 遇到 429／503 時暫停新查詢，依 Retry-After 退避，最少 1 分鐘、最多 1 小時。關閉瀏覽器後仍保留快取及退避時間。
- 查詢中先保留卡片，取得披露後套用標示或遮罩。狀態列分開顯示「背景確認」「未找到披露」「尚未確認」。
- 年齡驗證、登入、地區限制、逾時或格式異常都保留為未知，不會當成未找到披露；插件不自動通過驗證。
- 可在彈窗點「清除查詢快取」，目前畫面會重新確認；清除不會消除 Steam 的限流等待時間。

## 支援範圍及限制

- 支援 Steam 首頁 `/`（含語言／追蹤參數）、`/search/` 與 `/app/<id>/`；詳情頁只提示，不遮蔽整頁。
- 首頁涵蓋推薦輪播、特惠膠囊、熱門列表，以及帶有 app 連結和圖片的新版卡片；同一遊戲的卡片共用當前頁面已取得的訊號。
- 願望清單、獨立特價活動頁、Steam 桌面客戶端不在本版範圍。
- 搜尋卡片的 `data-ds-tagids` 只包含部分標籤，不保證完整。只使用每張卡片的資訊，絕不使用側欄 tag 來推定遊戲。
- 列表沒附帶 AI 揭露時，由背景查詢商品頁補足；若無法取得完整頁面，仍保持未知。
- `7926` 是 Artificial Intelligence tag。它可能表示題材，**不代表生成式 AI 使用證據**。
- 未取得訊號／格式異常保持可見，不能解讀為「沒有 AI」。第一次查詢有等待時間，不能保證封面完全不閃現。
- 揭露標題支援繁中、簡中、英文；tag ID 與語言無關，詳情頁文字 tag 支援這三種語言。
- 只計算可識別的單一 app 卡片；不推定組合包或套件的 AI 狀態。計數以頁面卡片筆數為單位。
- Steam 更換頁面結構後，可能需要更新插件。

## 開發

使用 Node.js 22+：

```sh
npm ci
npm run check
npm run dev
```

`dist/` 是可載入的插件。`npm run dev` 僅監聽 `127.0.0.1:4173`。

- 首頁預覽：`http://127.0.0.1:4173/`
- 首頁測試：`http://127.0.0.1:4173/?test=1`
- 動態查詢與快取整合測試：`http://127.0.0.1:4173/?lookup=1`
- 搜尋預覽：`http://127.0.0.1:4173/search/`
- 搜尋頁瀏覽器測試：`http://127.0.0.1:4173/search/?test=1`
- 詳情頁瀏覽器測試：`http://127.0.0.1:4173/app/4517370/`
- 單檔預覽：執行 `node scripts/package-preview.mjs`，開啟 `artifacts/preview.html`。

瀏覽器測試以 Chrome API 替身測試內容腳本與彈窗，使用虛構遊戲與實際觀察到的 Steam DOM 結構。動態查詢 fixture 使用正式 Resolver 加上合成 HTTP 回應。它不等於已在使用者 Chrome 安裝實測。測試替身不會進入 `dist/`。

可選的真實連線檢查：`node scripts/check-live.mjs 4517370 620`。只查明確指定的公開 App ID，檢查正式查詢器及重複快取命中；不在一般測試中連線。
