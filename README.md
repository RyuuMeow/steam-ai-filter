# Steam AI Filter · v0.2.0

Chrome 桌面版 Steam 商店過濾插件。頁面載入時讀取當前頁面資料，依拉桿設定標示或遮蔽遊戲。

## 安裝

1. 開啟 Chrome 的 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 點「載入未封裝項目」，選擇交付的 **steam-ai-filter** 資料夾（裡面直接有 manifest.json）。
4. 重新整理已開啟的 Steam 首頁、搜尋頁或遊戲頁，再從工具列開啟插件。

已提供編譯後的插件，安裝不需要 Node.js。ZIP 請先解壓縮，勿直接選 ZIP。

## 更新舊版

以新版檔案覆蓋原本載入的插件資料夾（不要多包一層子目錄），在 `chrome://extensions` 點插件的重新載入按鈕，確認版本是 **0.2.0**，再重新整理 Steam 首頁。只重新整理 Steam 不會讓 Chrome 重新讀取新的 manifest。

## 使用

| 檔位 | 規則 | 拉桿 |
|---|---|---|
| 關閉 | 移除插件的頁面標示與遮蔽 | 灰色 |
| 標示（預設） | 標出 AI 揭露或人工智慧 tag，全部保留 | 淡藍、柔光 |
| 揭露 | 遮蔽當前列表提供 AI 揭露的遊戲 | 飽和藍、較強光暈 |
| 廣泛 | 額外遮蔽人工智慧 tag 命中的遊戲 | 藍紫、切入時短暫流光 |

拖曳中預覽拉桿效果，放開後套用。支援鍵盤方向鍵、Home、End，以及系統的減少動畫設定。

- 被封鎖的卡片保留原尺寸，以純底色、垃圾桶圖示及原因文字遮蔽。已揭露者顯示「AI 生成內容」，只有 tag 者顯示「人工智慧標籤」。點擊遮罩可查看原因與例外。
- 頁面上可「暫時顯示」及「恢復過濾」。這個暫時狀態在刷新頁面或變更等級時結束。
- 點卡片標籤，或展開「查看命中原因與例外」，可查看依據並設為「永遠顯示」。
- 彈窗底部可移除「永遠顯示」的遊戲。
- 等級與例外名單保存在本機。插件不傳送瀏覽資料，不額外請求遊戲詳情，不使用 AI API。

## 支援範圍及限制

- 支援 Steam 首頁 `/`（含語言／追蹤參數）、`/search/` 與 `/app/<id>/`；詳情頁只提示，不遮蔽整頁。
- 首頁涵蓋推薦輪播、特惠膠囊、熱門列表，以及帶有 app 連結和圖片的新版卡片；同一遊戲的卡片共用當前頁面已取得的訊號。
- 願望清單、獨立特價活動頁、Steam 桌面客戶端不在本版範圍。
- 搜尋卡片的 `data-ds-tagids` 只包含部分標籤，不保證完整。只使用每張卡片的資訊，絕不使用側欄 tag 來推定遊戲。
- 實際抽查的搜尋卡片沒有 AI 揭露，因此「揭露」檔在這些列表可能不會遮蔽任何遊戲。「廣泛」檔可使用已附帶的 tag。
- `7926` 是 Artificial Intelligence tag。它可能表示題材，**不代表生成式 AI 使用證據**。
- 未取得訊號／格式異常保持可見，不能解讀為「沒有 AI」。
- 揭露標題支援繁中、簡中、英文；tag ID 與語言無關，詳情頁文字 tag 支援這三種語言。
- 只計算可識別的單一 app 卡片；不推定組合包或套件的 AI 狀態。計數以頁面卡片筆數為單位。
- Steam 更換頁面結構後，可能需要更新插件。

## 開發

使用 Node.js 22+：

```sh
npm ci
npm run check
npm run dev
```

`dist/` 是可載入的插件。`npm run dev` 僅監聽 `127.0.0.1:4173`。

- 首頁預覽：`http://127.0.0.1:4173/`
- 首頁測試：`http://127.0.0.1:4173/?test=1`
- 搜尋預覽：`http://127.0.0.1:4173/search/`
- 搜尋頁瀏覽器測試：`http://127.0.0.1:4173/search/?test=1`
- 詳情頁瀏覽器測試：`http://127.0.0.1:4173/app/4517370/`
- 單檔預覽：執行 `node scripts/package-preview.mjs`，開啟 `artifacts/preview.html`。

瀏覽器測試以 Chrome API 替身測試內容腳本與彈窗，使用虛構遊戲與實際觀察到的 Steam DOM 結構；它不等於已在使用者 Chrome 安裝實測。測試替身不會進入 `dist/`。
