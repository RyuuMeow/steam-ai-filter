# v0.10.2 驗證紀錄

日期：2026-10-21

## 結果

- TypeScript strict、建置與 **64 項 Node 測試**通過。
- **25 個瀏覽器情境、435 項斷言**通過，涵蓋互動、卡片分組、版面、失效還原與 Mask 效能。
- `npm run package:check`：**41 個安裝檔案**與建置一致，包含三語描述、Tabler MIT 圖示及授權，不含測試替身。
- 已目視檢查三語主面板、霧面遮罩、三個操作按鈕、眼睛恢復按鈕與實際展開的下拉選單。
- 發版流程另行驗證版本標籤、安裝包一致性與 RAR 解壓後的完整檔案內容，通過後發布 [v0.10.2 Release](https://github.com/RyuuMeow/steam-ai-filter/releases/tag/v0.10.2)。

## 本次驗收

- 設定、返回、下拉、眼睛及用途圖示統一為 Tabler 圓角框線圖示；用途標題與選項透過字重、顏色及間距區分。
- 標籤保留圓角膠囊、圖示與文字，背景改為低強度柔邊白色矩形。100px 窄卡片且 overflow 可見時，矩形和長標籤仍在卡片範圍內。
- 下拉選單使用頂層懸浮，開啟前後其他欄位座標與面板高度不變。下方空間足夠時向下，靠近底部時向上；英文、繁中、簡中、滑鼠、鍵盤、Escape 取消、Tab 與外部點擊收起均通過。
- 先以 200 張卡片、20 次不變設定刷新重現 **8,000 次遮罩更新、108,000 次 DOM 變動**；修正後均為 **0**。hover 恢復只處理一張遮罩；真實新增子元素和遊戲名稱更新仍會重繪並維持無障礙狀態。此數據來自本機合成卡片，並非真實 Steam FPS。
- 遮罩改為既有封面圖的局部模糊，移除 backdrop-filter；卡片分組排除插件自己的縮圖和圖示，避免干擾 Steam 推薦結構。
- 真實拖曳具有連續中間值，滑塊與填色同步，放開保存正確檔位；鍵盤每次切一檔。
- 遮蔽顯示「AI生成內容」，hover／鍵盤聚焦淡入三個無底色白字動作。點空白區或解除按鈕顯示單張卡片，首次不開視窗、不跳轉；眼睛恢復遮蔽，圖示在 32px 目標中置中。
- 已先重現 static 卡片在恢復遮蔽後丟失定位、讓模糊層覆蓋頁面的問題；修復後檢查眼睛恢復及連續三次 hover 移入移出，遮罩尺寸與位置均保持在卡片內。手動解除、hover 與持久例外分開管理；切模式或 DOM 換 app 清理暫時狀態。
- 單次不感興趣不開自動化，測試涵蓋可信任點擊、去重、限流、登入失敗、帳號切換及回讀確認；失敗不建立自動重試，合成點擊不寫入帳號。
- 三語字典鍵與參數一致，瀏覽器預設語言、設定保存、重新開啟、跨分頁及已開視窗即時換語言均通過；遊戲名稱與揭露原文保留。
- 七項用途、快取期限、網路節奏、首頁、搜尋 500 張卡片、完整推薦、輪播、詳情頁與十種失效還原組合維持通過。

三語與所有設定分類保持在 320px 彈窗內。測試使用本機 Chromium、Chrome API 替身及合成 Steam HTTP 回應，未替使用者重新載入真實 Chrome 插件，也未修改真實 Steam 帳號。
