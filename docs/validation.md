## 結果

- `npm run check`：TypeScript strict、建置與 **53 組 Node 測試**通過。
- 正式編譯資產搭配離線 Steam DOM／Chrome API 替身，涵蓋用途選項、既有卡片版面、查詢與自動忽略。

## 用途選項

- 六項關鍵字包獨立比對英文、繁中及簡中；美術預設開啟，其餘關閉。舊版升級不需要寫入遷移資料，其他設定保留。
- 驗證混合用途、否定句、手繪聲明、背景音樂、翻譯對話、text-to-speech、程式碼撰寫及未明用途；不使用單獨 model／asset／script／character 作用途證據。
- 收合清單、選取摘要、各項開關、快速連續設定、分頁同步、重新開啟、保存失敗還原與重試均通過。
- 相同分類結果用於遮蔽、剔除與自動忽略；全關、取消用途及手動例外會阻止已不符合條件的待辦，送出前也會重新確認。
- 快取分類不包含選項，切換不需重新查詢；揭露變更、晚到結果及同款重複卡片均套用目前設定。

## 驗證邊界

- 分類是本機關鍵字推斷，無法保證涵蓋全部語言、寫法、複雜否定或跨句指代。
- 本次使用離線頁面、合成帳號與 HTTP 回應；未替使用者在 Chrome 重新載入插件，也未向真實 Steam 帳號送出忽略操作。
- 登入狀態、Steam 限流及未辨識的自訂版面仍可能影響使用；30 秒為插件間隔，不是官方安全速率保證。
