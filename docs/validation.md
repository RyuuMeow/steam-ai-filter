## 首頁修正

實際首頁的 `.home_content.single` 在推薦理由中連到另一款遊戲，舊版因混合 App ID 停止擴張，只剔除內部圖組，留下標題、操作、價格與外層間距。

[首頁單款推薦測試](../tests/home-single.html) 先以舊資產重現失敗，再驗證修正後的 20 項行為：

- 整個標題、操作、圖組及價格一起遮蔽／剔除，專屬外層間距收起，正常相鄰推薦上移。
- 純文字推薦理由不改變目標 app，也不污染其標籤。
- 混合遊戲、含其他圖片的推薦理由及帶獨立內容的外包裝不會被整塊處理。
- 暫時顯示、例外、節點重用、模式切換及關閉均還原尺寸與無障礙屬性。

## Node 測試涵蓋

四檔規則、例外、保守程式碼分類、manifest／圖示、正式商品頁解析、快取保存與過期、併發去重、取消／清除競態，以及 background 訊息來源。

自動忽略以合成帳號、HTTP、時鐘與儲存驗證：預設關閉、帳號綁定、跨分頁去重、30 秒間隔、重啟、送出前設定覆核、已忽略跳過、成功回讀、未知結果重試、429／503 等待、登入失效、切換帳號、三次失敗停止與儲存錯誤。

## 驗證邊界

- 真實 DOM 已確認首頁推薦、Next Fest 詳細列、標準水平輪播及 `trailercarousel` 結構；修正後的互動與還原由離線重現驗證，未由工具替使用者重新安裝或載入插件。
- 真實帳號寫入、登入 cookies 的當下效果與 Steam 的限制，未以使用者帳號執行測試。30 秒是插件採用的間隔，並非官方保證的安全速率。
- 過去公開頁面查詢已確認可解析 AI 揭露，也確認年齡驗證 redirect 會保持未知。匿名 Node 查詢不能證明登入後的成人商品頁一定可用。
- 固定尺寸 fixture 驗證 popup 從 25／95／800px 初始視窗都回到 320px；不等同真實工具列 popup 的所有宿主行為。
- [GitHub Actions Check](https://github.com/RyuuMeow/steam-ai-filter/actions/runs/39428274478) 已通過型別檢查、52 組 Node 測試、建置及安裝包比對；瀏覽器 fixture 的結果來自前述本機驗證。
