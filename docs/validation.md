# v0.9.0 驗證紀錄

日期：2026-10-21

## 結果

- `npm run check`：TypeScript strict、建置及 **58 組 Node 測試**通過。
- 本機 Chromium **23 個瀏覽器情境、360 項斷言**通過；最後的空揭露正文修正另重跑用途與詳情頁，以及核心／分類測試。
- `npm run package:check`：v0.9.0 的 **20 個安裝檔案**與建置一致，含 MIT LICENSE，不含測試替身。
- 已實際檢視標記、遮蔽及設定頁截圖，確認獨立純色標籤、綠色圓底勾勾及返回 icon。未發布 Release。

## 本次驗收

- 舊關閉／標示轉為關閉／標記；舊揭露／廣泛依原呈現轉為遮蔽／隱藏。保留用途、例外與其他開關，無效設定採預設值。
- 用途不明僅涵蓋有可讀正式揭露但無可辨識用途的遊戲；只有題材 tag、查詢失敗及只有揭露標題不會命中。全未選、混合用途、否定句及例外均符合共用規則。
- 標記模式產生獨立 AI／用途塊；遮蔽與隱藏無此標籤。三個啟用模式共用已檢查圖示，遮罩保留綠勾；關閉移除所有狀態與過濾，不檢查新卡片，晚到結果也不重新套用。
- 齒輪 → 設定分類 → 分類內頁；返回逐層還原焦點與捲動。連續設定、重新開啟、跨分頁同步、儲存失敗還原與重試通過。
- 重新檢查間隔套用既有檢查時間；30 天結果跨 worker 重啟沿用、縮短間隔重新查詢。失敗重試與 Steam 冷卻不被長期快取、清除快取或網路設定覆蓋。
- 全域請求間隔、可調並行數與執行中降低上限通過；延遲的設定讀取不能在關閉後啟動查詢。自動忽略沿用獨立節奏及送出前驗證。
- 首頁完整推薦、動態卡片、詳細列、輪播、詳情頁推薦、暫時顯示及失效還原維持正確。
