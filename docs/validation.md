# v0.10.0 驗證紀錄

日期：2026-10-21

## 結果

- TypeScript strict、建置與 **64 項 Node 測試**通過。
- **24 個瀏覽器情境、407 項斷言**通過。完整回歸後，更新舊介面預期的四個情境分別重跑通過；最後的操作中狀態調整重跑 interactions 通過。
- `npm run package:check`：**28 個安裝檔案**與建置一致，包含三語描述、CC0 圖示及授權，不含測試替身。
- 已目視檢查三語主面板、霧面遮罩、三個操作按鈕、眼睛恢復按鈕與實際展開的下拉選單。
- 未發布 Release，可重新載入 `extension/` 試用。

## 本次驗收

- 主面板低對比分隔線、現成 CC0 設定圖示、標籤局部漸層、命中黃勾、遮蔽卡片省略勾。移除計數、暫時顯示與重複說明，下拉選單套用一致樣式。
- 真實拖曳具有連續中間值，滑塊與填色同步，放開保存正確檔位；鍵盤每次切一檔。
- 遮蔽顯示「AI生成內容」，hover／鍵盤聚焦淡入三個動作。點空白區或解除按鈕顯示單張卡片，首次不開視窗、不跳轉；眼睛恢復遮蔽。
- hover 解除預設關閉；開啟時移出即恢復。手動解除、hover 與持久例外分開管理；切模式或 DOM 換 app 清理暫時狀態。
- 單次不感興趣不開自動化，測試涵蓋可信任點擊、去重、限流、登入失敗、帳號切換及回讀確認；失敗不建立自動重試，合成點擊不寫入帳號。
- 三語字典鍵與參數一致，瀏覽器預設語言、設定保存、重新開啟、跨分頁及已開視窗即時換語言均通過；遊戲名稱與揭露原文保留。
- 七項用途、快取期限、網路節奏、首頁、搜尋 500 張卡片、完整推薦、輪播、詳情頁與十種失效還原組合維持通過。

三語與所有設定分類保持在 320px 彈窗內。測試使用本機 Chromium、Chrome API 替身及合成 Steam HTTP 回應，未替使用者重新載入真實 Chrome 插件，也未修改真實 Steam 帳號。
